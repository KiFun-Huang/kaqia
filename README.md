# Kaqia (咔嚓) - 原生 Windows 截图美化工具

Kaqia 是一款专为 Windows 设计的高性能、原生截图与图片编辑美化工具。它不仅能捕捉你的屏幕，还能瞬间将普通的截图转化为极具设计感的分享图。

## 核心特性

### 1. 极致原生性能
*   **秒开体验：** 采用 C# WPF + GDI+ 底层接口，瞬间抓取全屏像素，完美适配多显示器与高 DPI 缩放。
*   **静默运行：** 常驻系统托盘，内存占用极低，随时待命。

### 2. 高效的截图与调整
*   **精准框选：** 实时显示鼠标的屏幕坐标 (X/Y)；框选完成后，顶部会显示截图的具体尺寸（宽 × 高）。
*   **尺寸微调：** 框选区域支持 8 向拖拽缩放，也可以按住中间随意移动；如果你需要极度精确的尺寸，甚至可以**直接点击顶部数字输入具体像素值**。
*   **智能防遮挡工具栏：** 工具栏默认附着在截图框外部右下角；当截图区域过大时会自动缩进内部。如果你觉得位置不顺手，可以**按住工具栏最左侧的“把手”自由拖拽**到屏幕任何地方。

### 3. 高级外观美化
*   **一键悬浮卡片：** 提供智能初次预设，开启阴影即自动分配最佳的留白和白色底座。
*   **智能圆角与描边：** 支持无锯齿的圆角效果，以及可自定义颜色的独立描边。
*   **状态记忆：** 你所调整的任何圆角、留白、阴影或自定义颜色，软件都会自动记忆，下次截图时完美还原。

### 4. 专业标注系统 (Object-Based)
*   **全能工具箱：** 矩形、椭圆、箭头、自由画笔、多行文字。
*   **二次编辑：** 每一个标注都是独立对象。画完后可随时选中进行移动、缩放、旋转或变色。
*   **点击穿透：** 镂空的图形（如矩形、圆形）支持**点击穿透**。即使一个小图标被一个大号矩形框在中间，你依然可以隔着“空气”直接点击到里面的小图标。
*   **动态属性：** 选中线条时可调整“粗细”，选中文字时滑块会自动变为调整“字号”。

### 5. 自定义贴纸库
*   **个人品牌：** 支持上传本地 PNG/JPG 图片作为贴纸。
*   **无损等比缩放：** 贴纸加入后会保持完美的原始比例，拖拽四角调整大小时默认等比缩放，告别画面拉伸或压扁。

## 常见操作疑问（Q&A）

**Q: 为什么多屏幕下，工具栏有时候在截图框外面，有时候在里面？**
A: 这是为了防止工具栏“跑出屏幕边界”的智能防遮挡设计。如果你截了一个超大的图（高度超过 600px），工具栏会自动乖乖躲进截图框内部的右下角。如果你还是觉得挡视线，**按住工具栏最左侧的 `⋮` 图标，可以把它拖到任何你想放的地方**。

**Q: 为什么我画了一个大方框，但是我想选中它的时候怎么点都没反应？**
A: 因为我们优化了“点击穿透”功能。现在大矩形或大圆形的“空心”部分默认是一团空气，是为了方便你点击它底层的东西。**你需要把鼠标精确移动到方框的“线条”上点击**，才能选中它。

**Q: 外观菜单里的“留白”和“底座颜色”怎么不见了？**
A: 留白和底座颜色功能主要为了配合阴影产生“卡片悬浮感”。你需要**先勾选“启用悬浮阴影”**，底下的留白和底色选项才会展示出来。

**Q: 我在顶部（或调色盘）输入了具体数值，为什么没生效？**
A: 输入框需要你确认输入完成。修改完数值或 HEX 颜色代码后，**请按一下键盘上的 `Enter`（回车键）**，或者用鼠标点击一下画布空白处，修改就会立即生效。

**Q: 为什么开始画图后，截图框外面的蓝色调整点就不见了？**
A: 这是防误触机制。一旦你点击了画笔、文字等标注工具，截图外框就会被“锁定”，防止你在边缘画图时不小心拉偏了截图区域。**如果需要再次调整截图框大小，请在工具栏点回“选择 (↖)”工具即可。**
