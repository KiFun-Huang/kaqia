# Kaqia (卡恰) - 截图与贴纸工具

Kaqia 是一款专为 Windows 打造的轻量、高性能截图与自定义贴纸工具。它不仅能帮助你快速捕获屏幕，还能通过丰富的标注工具和个人贴纸让截图更具表现力。

## 🚀 快速开始

### 1. 下载使用 (推荐)
你可以直接从 [GitHub Releases](https://github.com/KiFun-Huang/kaqia/releases) 页面下载最新的发布版本：
- 下载 `Kaqia_v1.0.0_win-x64.zip`。
- 解压后双击 `KaqiaApp.exe` 即可运行。
- **无需安装**，绿色免安装版本，解压即用。

### 2. 自行编译 (针对开发者)
如果你希望根据源代码进行二次开发或自行编译，请参考下方的[编译说明](#编译与使用说明)。

## 核心特性

*   **基础标注**：内置矩形、圆形、箭头、画笔和文字输入等基础工具，所有标注绘制后均可再次选中、移动或二次编辑。
*   **自定义贴纸**：支持批量上传本地图片作为贴纸库，可在截图中自由拖放、调整大小，并支持在管理模式下直接拖拽重新排序。
*   **一键美化**：提供圆角、描边、边缘留白和悬浮阴影效果，让普通截图一秒变精美卡片。
*   **多屏适配**：原生支持多显示器和高 DPI 环境，工具栏与属性面板智能跟随，无惧跨屏操作。
*   **高效流转**：支持全局快捷键唤起，编辑完成后点击“完成”即可将图片复制到剪贴板，同时支持自动保存到本地目录。

## 编译与使用说明

### 环境要求
*   Windows 操作系统
*   [.NET 10.0 SDK](https://dotnet.microsoft.com/download)

### 编译步骤
1. 克隆或下载本仓库代码到本地。
2. 在项目根目录下打开终端（如 PowerShell 或 CMD），运行以下命令进行编译：
   ```bash
   dotnet build
   ```
   *注：你也可以使用 Visual Studio 2022+ 打开项目根目录下的 `Kaqia.slnx` 解决方案文件直接编译。*

### 运行程序
编译成功后，可以通过以下命令直接运行主程序：
```bash
dotnet run --project KaqiaApp
```
或者在文件资源管理器中找到并双击运行可执行文件：`KaqiaApp\bin\Debug\net10.0-windows\KaqiaApp.exe`。

### 使用指南
1. **静默运行**：程序启动后会在系统托盘（右下角任务栏）常驻。
2. **开始截图**：使用系统全局快捷键（可在托盘右键的“设置”中自定义，通常默认为 Ctrl+Alt+A 等常用组合）即可随时唤起截图界面。
3. **编辑与标注**：
   - 框选你需要截取的屏幕区域。
   - 使用附带的工具栏进行文字、框线标注，或打开贴纸面板添加个性化图案。
   - 使用外观面板快速为截图加上“高级感”的阴影和圆角。
   - 标注放置后，可随时用“选择”工具（↖）选中它们并进行拖拽移动或缩放。
4. **完成导出**：点击绿色的 **[完成]** 按钮，图片将自动复制到系统剪贴板，随处粘贴即可使用。
