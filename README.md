# Kaqia (咔嚓) - 原生 Windows 截图美化工具

Kaqia 是一款专为 Windows 设计的高性能、原生截图与图片编辑美化工具。它不仅能捕捉你的屏幕，还能瞬间将普通的截图转化为极具设计感的分享图。

<img src="logo.png" width="128" alt="Kaqia Logo">

## 核心特性

### 1. 极致原生性能
*   **秒开体验：** 采用 C# WPF + GDI+ 底层接口，瞬间抓取全屏像素，完美适配多显示器与高 DPI 缩放。
*   **静默运行：** 常驻系统托盘，内存占用极低，随时待命。

### 2. 高级外观美化
*   **智能圆角：** 采用硬件加速的裁剪技术，提供丝滑无锯齿的圆角效果。
*   **现代阴影：** 支持多层弥散性深色阴影，让截图具备 macOS/Windows 11 的悬浮质感。
*   **设计感留白：** 可自由调节外围画布大小，支持纯色及渐变背景（如经典的 Mac 风格渐变）。
*   **精致描边：** 支持独立控制截图边缘的描边粗细与颜色。

### 3. 专业标注系统 (Object-Based)
*   **全能工具箱：** 矩形、椭圆、箭头、自由画笔、多行文字。
*   **二次编辑：** 每一个标注都是独立对象。画完后可随时选中进行移动、缩放、旋转或变色。
*   **独立记忆：** 每个工具（如矩形、文字）独立记录上次使用的颜色与粗细。

### 4. 自定义贴纸库
*   **个人品牌：** 支持上传本地 PNG/JPG 图片作为贴纸。
*   **交互控制：** 贴纸支持鼠标拖拽位移、滚轮缩放以及 Shift+滚轮自由旋转。
*   **持久化存储：** 自动管理贴纸库，跨 Session 记录你的常用素材。

### 5. 系统集成与设置
*   **自定义热键：** 支持全局快捷键录制（默认 `Ctrl + Alt + S`）。
*   **开机自启：** 一键设置随系统启动。
*   **自动保存：** 支持设置默认保存目录，点击“完成”时同步保存到本地。
*   **透明剪贴板：** 采用 PNG 流推送技术，粘贴到微信、钉钉等软件时完美保留透明阴影。

## 快速开始

### 开发环境要求
*   .NET 10.0 SDK 或更高版本
*   Windows 10/11 操作系统

### 编译与运行
1.  克隆仓库
2.  在项目根目录下执行：
    ```powershell
    dotnet build
    ```
3.  运行生成的 `.exe` 文件即可。

## 技术栈
*   **语言:** C# 13
*   **框架:** .NET 10 WPF
*   **依赖:** 
    *   System.Drawing.Common (底图片处理)
    *   Hardcodet.NotifyIcon.Wpf (系统托盘支持)
